# Exercise 3.9 pros and cons PVC and Cloud database

Choosing Google Cloud SQL provides automated high availability, effortless point-in-time recovery, zero-downtime maintenance, and zero operational overhead, though it comes with a 20–40% managed infrastructure cost premium and strict configuration limits. Conversely, running PostgreSQL on GKE with PVCs dramatically reduces raw cloud spend and offers complete freedom over custom extensions, resource limits, and configuration tuning; however, it shifts a heavy engineering burden onto your team, requiring manual setup of stateful operators, database-consistent backup tools (like pgBackRest), and complex failover management during node drains. Ultimately, Cloud SQL trades higher direct infrastructure costs for minimal labor and high reliability, while GKE-hosted Postgres minimizes licensing/compute spend at the cost of significantly higher long-term maintenance and operational risk.
